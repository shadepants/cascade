# CASCADE — Dev Tools Audit Report

## Audit Scope
Audited the procedural generation algorithm for map creation, focusing on Deterministic Seeding, Coordinate-to-Tile Mapping, Temporal Delta Logic, and Chunk Management as specified.

## 1. Deterministic Seeding
**Analysis:** The random number generation relies on `SeededRNG` (a mulberry32 algorithm implementation) and `generatePermutation` in `src/utils/noise.ts` (using Fisher-Yates with a linear congruential generator).
**Findings:**
- **Robust Determinism:** The `SeededRNG` produces fully reproducible sequences given the same seed. There are no observable "global state" leaks or reliance on non-deterministic system values (like `Date.now()`, which is safely isolated as a fallback in `worldgen.ts` before the `SeededRNG` is instantiated).
- **Integrity Verified:** Jumping between coordinates at different time intervals will currently yield identical base terrain since `generateTerrain` initializes `SeededRNG` and noise functions predictably from the `seed`.

## 2. Coordinate-to-Tile Mapping
**Analysis:** Terrain generation (`generateTerrain` in `src/world/terrain.ts`) uses a multi-pass approach:
1.  **Elevation:** 4-octave FBM noise combined with tectonic plate simulations.
2.  **Moisture:** Wind-driven moisture transport modeling orographic precipitation.
3.  **Classification:** Threshold-based logic (`classifyBiome`) assigning biomes based on final elevation and rainfall values.

**Findings:**
- **Robustness:** The threshold mapping effectively prevents impossible transitions (e.g., 'ocean' to 'mountain') by layering the values properly. For instance, elevation strictly defines water layers (<0.3) and high altitudes (>0.85). The continuous nature of FBM noise guarantees gradual transitions over coordinates.
- **Mathematical Drift / Bounds Integrity:** Values derived from the FBM noise in `createFBM2D` are properly normalized, and tectonic modifications are explicitly clamped using `Math.max(0, Math.min(1, baseElevation + tectonicMod))`. There is no mathematical drift that would allow values to exceed expected bounds [0, 1].

## 3. Temporal Delta Logic (Critical Finding)
**Analysis:** The current algorithm generates a static 2D grid and lacks continuous temporal evolution for the base terrain.
**Findings:**
- **Missing 4D Noise:** The algorithm uses a 2D base `createFBM2D(seed, 4)` and does not factor "time" (`t`) into terrain noise generation.
- **Echo System Limitations:** Historical modifiers are applied via the "Echo System" in `src/simulation/tick.ts`. This system iterates through the entire $N \times N$ map every simulation year to decay tile modifiers (e.g., `duration - 1`).
- **Performance Risk:** The $O(N^2)$ time-complexity decay loop is inefficient and will bottleneck if map sizes are scaled up or if an infinite chunking system is introduced. A 4D noise function (or 3D where $z$ = time) is required to dynamically layer historical modifiers efficiently without large grid traversals.

## 4. Chunk Management (Critical Finding)
**Analysis:** The current codebase has no chunk boundary management.
**Findings:**
- **Single 2D Array:** The entire map is generated monolithically as a fixed-size `Tile[][]` array defined by `size`.
- **Interpolation Gaps:** Because there is no chunk system, the current tectonic simulation (which initializes plates across the entire `size` grid) and moisture pass (which iterates linearly from west to east across the whole grid) are incompatible with infinite map chunking. Introducing chunks would currently cause "seams" and "tears" across boundaries.

## 5. Standard Tile-Based Rendering Compatibility
**Analysis:** The data structure generated (`GameMap` with `width`, `height`, and `tiles` array) is entirely standard.
**Findings:**
- **Compatible:** The resulting 2D arrays are natively compatible with tile-based renderers like Pixi.js (currently used in the stack) and React grid components.

## Pseudocode Refactor: 4D Noise & Infinite Chunking

This refactor outlines how to introduce chunk-based management and temporally-aware (4D/3D) noise layering to resolve the identified bottlenecks and missing features.

```typescript
// 1. Refactored Noise Function (3D: x, y, t)
function createFBM3D(seed, octaves = 4, persistence = 0.5, lacunarity = 2.0) {
  // Setup 3D noise (e.g., OpenSimplex3D or modified Perlin3D)
  const noiseFuncs = Array.from({ length: octaves }, (_, i) => createNoise3D(seed + i * 1337));

  return function fbm3D(x, y, t) {
    let total = 0, frequency = 1, amplitude = 1, maxValue = 0;
    for (let i = 0; i < octaves; i++) {
      total += noiseFuncs[i](x * frequency, y * frequency, t * frequency) * amplitude;
      maxValue += amplitude;
      amplitude *= persistence;
      frequency *= lacunarity;
    }
    return total / maxValue;
  };
}

// 2. Chunk-Aware Generator
const CHUNK_SIZE = 32;

function generateChunk(seed, chunkX, chunkY, t) {
  const rng = new SeededRNG(seed + chunkX * 73856093 ^ chunkY * 19349663);
  const elevationNoise = createFBM3D(seed, 4);
  const modifierNoise = createFBM3D(seed + 100, 2); // Fast changing historical layer

  const tiles = [];
  const startX = chunkX * CHUNK_SIZE;
  const startY = chunkY * CHUNK_SIZE;

  for (let y = 0; y < CHUNK_SIZE; y++) {
    const row = [];
    for (let x = 0; x < CHUNK_SIZE; x++) {
      const globalX = startX + x;
      const globalY = startY + y;

      // Base terrain ignores time or changes extremely slowly
      const baseElevation = normalize(elevationNoise(globalX * 0.05, globalY * 0.05, t * 0.0001));

      // Layer historical/temporal modifiers based on time (t)
      const historicalMod = normalize(modifierNoise(globalX * 0.1, globalY * 0.1, t * 0.05)) * 0.2 - 0.1;

      const finalElevation = Math.max(0, Math.min(1, baseElevation + historicalMod));

      // Calculate rainfall via continuous noise rather than a directional pass to prevent chunk seams
      const localRainfall = getRainfallNoise(seed, globalX, globalY, t);

      row.push({
        biome: classifyBiome(finalElevation, localRainfall),
        elevation: finalElevation,
        rainfall: localRainfall,
        walkable: true
      });
    }
    tiles.push(row);
  }

  return { chunkX, chunkY, tiles };
}
```
